# Implementation notes

- Normal and burst observations are generated by the hydraulic simulation
  utilities, with the configured pressure noise applied to both paths.
- Flow windows use the configured `FLOW_REDUCE` rule. `sum` aggregates
  interval rates; `volume` integrates rates over the interval duration.
- Source periods and parent burst events are assigned before windowing so that
  windows from one source do not cross dataset splits.
- The pressure graph is directed using the dominant direction across simulated
  operating time steps (ties retain the stored pipe direction).
  Consumers add self-loops explicitly and normalize rows; the GCN additionally
  applies symmetric degree normalization.
- Classifier heads return logits; softmax is applied only when probabilities
  are required.
- `scripts/metrics.py` matches localization predictions to the true burst
  `sample_id` set and reports CAC and `CAC_PB`.
- Detection metrics are DAC, PRE, REC, FAR and positive-class F1; localization
  metrics are LAC and macro-F1. Repeated seeds are summarized by mean and
  sample SD.
- Feature-fusion models apply the pressure-topology gate before the flow gate.
